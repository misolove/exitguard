Slack 이상징후 알림

Slack 설정 안내
  1. Slack에서 알림을 받을 채널용 Incoming Webhook을 만드세요. 워크스페이스 관리자 승인이 필요할 수 있습니다.
  2. 서버의 /etc/exitguard/config.json (또는 EXITGUARD_CONFIG 지정 파일)에서 기존 설정을 유지한 채 notify.webhook_url에 webhook을 저장하세요. 주소는 비밀 값입니다. 채팅·브라우저·Git에 붙여 넣지 말고 서버의 보안 편집 경로를 사용하세요.
  3. notify.min_level로 전송 기준을 선택하세요. 기본 MEDIUM 이상이며 HIGH로 올리면 높은 위험만 전송합니다. notify.dedupe_sec의 기본값은 600초입니다. 동일 알림이 반복되는 동안 중복 발송을 억제합니다.
  4. 파일 접근 권한을 제한하고 sudo systemctl restart exitguard-watch로 감시 서비스를 재시작하세요. 설정됨 표시는 파일 설정만 확인하며, 서비스의 적용 여부나 전송 성공을 보장하지 않습니다.

알림에는 기기·목적지 IP, 이벤트 제목 및 상세 정보가 포함될 수 있고 Slack으로 전송됩니다. 채널 접근 권한과 외부 전송 정책을 먼저 확인하세요.

이 화면은 설정을 저장하거나 메시지를 보내지 않습니다. 알림은 감시 서비스가 전송하므로 브라우저를 닫아도 동작합니다. 실제 수신 여부는 Slack 채널에서 확인하세요.
